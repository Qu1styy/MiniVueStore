# Mini Vue Store

Учебный проект на Vue.js, созданный для практики работы с компонентами, данными, вычисляемыми свойствами, событиями и пользовательским интерфейсом.

## Описание проекта

Это небольшое веб-приложение представляет собой карточку товара с возможностью:

- просмотра информации о товаре;
- изменения цвета и варианта товара;
- отображения статуса наличия на складе;
- добавления товара в корзину;
- расчёта стоимости доставки;
- просмотра отзывов и формы добавления нового отзыва;
- переключения вкладок "Reviews", "Shipping" и "Details".

Проект написан в стиле практики по изучению Vue.js и демонстрирует базовые принципы работы с компонентами и реактивностью.

## Как запустить проект

Так как проект является статическим и подключает Vue.js через CDN, его можно запустить простым открытием файла в браузере.

### Вариант 1: открыть напрямую

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

### Вариант 2: локальный сервер

Если хотите запустить через локальный сервер, выполните:

```bash
cd Vue_Practika
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```
